# Tourism Marketplace Mobile App

React Native mobile application for iOS and Android.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. For iOS (macOS only):
   ```bash
   cd ios && pod install && cd ..
   npm run ios
   ```

3. For Android:
   ```bash
   npm run android
   ```

## Development

- Start Metro bundler: `npm start`
- Run on iOS: `npm run ios`
- Run on Android: `npm run android`

## Note

This is a placeholder structure. Full React Native setup requires additional configuration files (ios/, android/ directories, metro.config.js, etc.) which are typically generated using `npx react-native init`.
